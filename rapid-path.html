Reaction Lab Games

Rapid Path

Controls

WASD or Arrow Keys

Goal

Create a path that connects all the given dots.

Game Modes

  • No Path
  • Show Path

Rules

  • Gain 3 seconds for each completed path.
  • Cannot go backwards.
  • Cannot go on black dots.

Menu

Pause to submit high score, view leaderboard, restart, change theme, mute sounds, or change to show path mode.
